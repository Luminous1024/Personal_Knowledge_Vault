# 1. 计算机系统概述
## 1.1 计算机系统的组成

>[!summary] 知识总览
> - 计算机系统的组成
> 	- 计算机系统 = 硬件 + 软件
> 		- 硬件：有形物理部件
> 		- 软件：程序 + 数据 + 文档
> 	- 软件和硬件的逻辑功能等价性
> 		- 同一功能可用硬件或软件实现
> 		- 从用户视角看：逻辑功能等价( 结果一致 )
> 	- Key：如何合理划分软硬件的功能边界
> 		- 原则：”成本 vs 性能“的权衡
> 		- 高频且硬件实现成本低的功能 $\to$ 硬件实现( 提升效率 )
> 		- 低频或复杂的功能 $\to$ 软件实现( 更灵活、更便宜 )

## 1.2 计算机硬件的基本组成
### 1.2.1 计算机硬件的基本组成( 冯诺依曼机结构 )

>[!summary] 冯诺依曼机的特点
> - 计算机由五大部件组成( 其中 $输入/输出$设备统称为 $I / O$设备 )
> - 指令和数据以同等地位存于存储器，可按地址寻访
> - 指令和数据用二进制表示
> - 指令由操作码和地址码组成
> - 存储程序
> - **以运算器为中心** —— $输入/输出$设备与存储器之间的数据传送通过运算器完成

>[!summary] 知识回顾与重要考点
> - 计算机硬件的基本组成
> 	- 五大部分
> 		- 输入设备
> 			- 将信息转换成机器能识别的形式
> 		- 输出设备
> 			- 将结果转换成人们熟悉的形式
> 		- 主存储器
> 			- 存放数据和程序
> 		- 运算器
> 			- 算术运算、逻辑运算
> 		- 控制器
> 			- 指挥各部件，使程序运行
> 	- 冯诺依曼结构
> 		- **首次**提出**”存储程序“**概念
> 		- 以**运算器**为中心
> 	- 现代计算机结构
> 		- 以**存储器**为中心
> 		- CPU = 运算器 + 控制器

### 1.2.2 计算机硬件的基本组成( 现代工程化结构 )

>[!summary] 要点总结
> - 计算机硬件的基本组成
> 	- 冯诺依曼机结构
> 		- CPU = 运算器 + 控制器 —— 运算器( 负责**算** ) = $ALU$ + 各类寄存器控制器( 负责**指挥**其他部件工作 )
> 		- 存储器
> 		- 输入设备、输出设备( 合称$I/O$设备 )
> 	- 线代工程化结构
> 		- **CPU = 数据通路 + 控制单元( 第二章 )**
> 			- 数据通路 = ALU( 第二章 ) + 各寄存器 + **内部连接**
> 			- 控制单元 = 控制器
> 		- 存储器( 第三章 )
> 			- 内存
> 				- Cache( 通常集成在CPU内，速度最快 )
> 				- <span style="color: #2e86c1; font-weight: bold;">主存储器( 可被CPU直接读写 ) —— 大多数语境下“内存”指“主存”</span>
> 			- 外存
> 				- 磁盘、固态硬盘( 不可被CPU直接读写 )
> 				- 光盘、磁带等海量存储设备( 速度慢、成本低 )
> 		- <span style="color: #f1ef62; font-weight: bold;">外部设备( $I/O$设备 )、设备控制器( 也称$I/O$控制器 或 $I/O$接口 )( 第七章 )</span>
> 		- <span style="color: #a4f162; font-weight: bold;">总线( 第六章 )</span> —— 包括：处理器总线、存储器总线、$I/O$总线

## 1.3 计算机软件

>[!summary] 知识回顾与重要考点
> - 计算机软件
> 	- 两类软件
> 		- 系统软件
> 			- 管理计算机系统的硬件资源，向上层应用程序提供服务
> 		- 应用软件
> 			- 按应用场景需要编制成的各种程序，直接为用户提供服务
> 	- 三个级别的语言
> 		- 高级语言、汇编语言、机器语言
> 		- 编译程序( 编译器 ) —— 将高级语言一次全部翻译为汇编语言，或直接翻译为机器语言
> 		- 汇编程序( 汇编器 ) —— 高级语言翻译为机器语言( 翻译一句执行一句 )
> 	- 软件和硬件的逻辑功能等价性
> 		- 同一个功能，既可以用硬件实现，也可以用软件实现
> 	- 指令集体系结构( $ISA：Instruction Set Architenture$ )
> 		- $ISA$定义一台计算机可以支持哪些指令，以及每条指令的作用是什么、每条指令的用法是什么
